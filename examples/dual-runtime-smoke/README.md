# Dual Runtime Smoke

This example is generated by:

```bash
pnpm smoke:dual-runtime
```

The smoke command resets `examples/dual-runtime-smoke/.cristalina-v4`, writes
one OpenClaw conversation-preference signal and one Hermes
conversation-preference signal into the same store, applies one OpenClaw owner
review action through the adapter boundary, then loads both runtime projections.

The generated `smoke-summary.json` records:

- the shared store root
- OpenClaw runtime/session/thread refs
- Hermes runtime/session/thread refs
- both projection manifest refs
- owner-review queue counts before and after the adapter action
- audit and validation log counts

The generated store is intentionally ignored by git. Re-run the command whenever
you need a fresh operational proof.
