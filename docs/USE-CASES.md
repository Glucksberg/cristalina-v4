# Cristalina v4
## Use Cases

**Status:** Draft

---

## 1. Personal Persistent Agent

An agent that:

- remembers user preferences
- tracks evolving projects
- accumulates editorial knowledge in a wiki
- preserves governed truth over time

This is the simplest and most immediate target use case.

## 2. Research Agent

An agent that:

- ingests many sources
- builds a temporal world model of ideas, papers, and claims
- maintains a synthesized knowledge wiki
- promotes only the strongest stable conclusions into canonical memory

This use case strongly exercises the distinction between `raw`, `wiki`, `world`, and `canon`.

## 3. Cross-Runtime Agent

A single memory core serving:

- OpenClaw
- Hermes Agent

The point is to keep identity and durable memory coherent across multiple runtimes.

## 4. Longitudinal Project Agent

An agent that tracks one long-lived initiative through time:

- goals
- constraints
- decisions
- contradictions
- revisions
- comparisons

This use case tests whether the architecture can accumulate serious history without becoming incoherent.
