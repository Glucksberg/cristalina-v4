# Cristalina v4
## Non-Goals

**Status:** Active Draft

---

Cristalina v4 is intentionally **not** trying to be all of the following:

## 1. Not Just Another Vector Memory Plugin

The project is not trying to compete only on semantic retrieval convenience.

## 2. Not A Generic RAG Framework

It may use retrieval techniques, but retrieval is not the center of the architecture.

## 3. Not A General Robotics Stack

The project may eventually inform embodied systems, but v4 is not a motor-control or robotics platform.

## 4. Not A Project-Management Tool

Projects may appear in memory, but the system is not primarily a PM system.

## 5. Not A Personal Wiki App

The wiki layer matters, but the project is not merely building an LLM-managed note app.

## 6. Not A Pure Knowledge Graph Product

Graph structure matters, but the system is not just a graph-memory engine.

## 7. Not A Constitution Without A Mind

The project is not trying to create a perfectly governed ledger that lacks a living runtime self.

## 8. Not A Runtime Without Law

The project is equally not trying to create a clever runtime memory layer that can mutate its own truth without discipline.
